# Changelog

All significant changes to the Black Excellence website project are tracked here.

## [0.2.0] - Part 2 CSS Styling and Responsive Design - 2026-09-13
### Feedback from Part 1
- No lecturer feedback or correction requests were received for Part 1.
- The existing semantic HTML structure and approved content were retained.

### Added
- Linked every HTML page to the external `css/styles.css` stylesheet.
- Added a CSS reset and consistent base styles across the website.
- Applied the approved black, gold, white and charcoal street-luxury colour palette.
- Added Playfair Display, Montserrat and Open Sans typography with a responsive type scale.
- Added Flexbox and CSS Grid layouts for navigation, cards, products, forms, content sections and footer areas.
- Added visual styles including borders, gradients, box shadows and consistent spacing.
- Added `:hover`, `:focus` and `:active` states for interactive elements.
- Added tablet and mobile media-query breakpoints.
- Added relative `rem`, `%` and `clamp()` units for responsive spacing and typography.
- Added responsive images using `srcset`, `sizes` and the `<picture>` element.
- Added desktop, tablet and mobile screenshot evidence to the README.

### Changed
- Upgraded all seven Part 1 pages from unstyled semantic HTML to a consistent responsive visual design.
- Updated README documentation from Part 1 to Part 2 requirements and testing evidence.

### Reserved for Later Parts
- Shopping-cart behaviour, payment processing, product filtering logic, form processing, wishlist, stock alerts and other JavaScript/e-commerce functionality remain intentionally unimplemented.

## [0.1.0] - Part 1 Initial Foundation - 2026-08-13
### Added
- Created the initial project folder structure.
- Added seven semantic HTML pages: Home, Our Story, Shop, Collections, Community, Enquiry and Contact.
- Added working navigation links across the full website.
- Integrated organisation history, mission, vision, audience, goals and planned website features from the project proposal.
- Added a basic enquiry form and multi-location contact-page structure.
- Added the Black Excellence logo and a visual sitemap.
- Added placeholder CSS and JavaScript files for later development parts.
- Added README documentation, timeline, sitemap, references and Part 1 scope notes.

### Clarified
- The project is treated as a new website development. Earlier wording that implied an existing website was corrected in the Part 1 proposal copy.

- Replaced abstract placeholder sneaker graphics with original Black Excellence product renders across the homepage, shop, collections and community pages.
- Added responsive product-image assets for Madiba 1, Ubuntu High, Heritage Runner and Durban Wave using `srcset` and `sizes`.
- Refined the Shop page into a cleaner school-project-level product section with a featured product showcase, clearer pricing, and a more consistent product-card layout.
- Revised visible website copy to sound more natural and brand-focused, removing assignment-style wording from the live pages.
- Improved readability on the Shop page by strengthening text contrast on dark product cards and support panels.
- Refined homepage copy to use shorter, more natural brand language and removed assignment-style phrasing from visible sections.
